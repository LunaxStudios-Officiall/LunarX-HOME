# UI acceptance

The UI preserves the existing LunarX logo, core route IDs and file/photo/app/desktop workflows while using a restrained cosmic palette: cyan signal color, electric blue, violet and magenta accents on a readable neutral surface.

The layout is tested by static inspection at 1920×1080, 1440×900, 1024×1366, 768×1024, 412×915, 390×844, 360×800 and 844×390. It includes dark, light and system themes, responsive navigation, visible focus, 44px-class controls, reduced-motion handling, empty/error/loading states and mobile-safe wrapping.

The Desktop and app catalog show capability truth rather than promising an unavailable provider.
