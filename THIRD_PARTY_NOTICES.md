# Third-party notices

LunarX ships metadata and source references, not third-party application binaries. xterm.js retains its upstream notice in `static/vendor/XTERM-LICENSE.txt`. Runtime dependencies are installed from configured Ubuntu/Python sources. Docker images for PostgreSQL, guacd, and Guacamole are pulled at install time and are not bundled.

Flathub entries record upstream metadata and licenses; the catalog does not grant redistribution rights. Visual Studio Code is not bundled. See `docs/THIRD_PARTY_AUDIT.md` for the current audit and `UNRESOLVED_PROJECT_LICENSE.md` for LunarX-owned licensing status.
