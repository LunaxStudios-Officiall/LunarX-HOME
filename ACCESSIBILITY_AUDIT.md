# Accessibility audit

Implemented: language and viewport metadata, semantic forms/labels, live status regions, keyboard-visible focus, high-contrast signal colors, responsive navigation, 44px-class controls, native dialog semantics, alt text for the logo/media and reduced-motion CSS. The UI is usable in dark/light/system themes and does not depend on hover alone.

Follow-up: run a screen-reader and automated WCAG audit on a live browser with the final target font/rendering stack.
